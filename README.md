# Notion ↔ Obsidian Sync

این مخزن فایل‌های Markdown قابل استفاده در Obsidian و تاریخچهٔ تغییراتشان را نگه می‌دارد. موتور اجرایی همگام‌سازی، زمان‌بندی یا اتصال فعال به Notion در کد فعلی وجود ندارد.

## ساختار

- `vault/`: یادداشت‌ها
- `vault/_meta/`: تنظیمات و نگاشت‌های پیشنهادی

## پیش‌فرض امن برای پیاده‌سازی آینده

همگام‌سازی غیرفعال و فهرست مجاز صفحه‌ها خالی است. پیش از فعال‌سازی، شناسهٔ صفحه‌های مشخص و مجاز را در `notion.page_ids` ثبت کنید و دسترسی integration را به همان صفحه‌ها محدود کنید. مصرف‌کنندهٔ آینده باید تنظیمات را اعتبارسنجی کند و برای حالت ناشناخته یا فهرست خالی متوقف شود؛ نباید به همهٔ صفحه‌های قابل دسترسی برگردد.

تأیید دستی هر تغییر و پرسش در تعارض حفظ شده است. خروجی کامل بار اول فقط باید به صفحه‌های مجاز محدود شود. این مخزن عمومی است؛ اطلاعات شخصی، محرمانه و توکن‌ها را وارد نکنید. مجوز استفادهٔ مجدد پروژه هنوز انتخاب نشده است.
