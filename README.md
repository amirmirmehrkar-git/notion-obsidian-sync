# Notion ↔ Obsidian Sync

این مخزن برای نگه‌داری خروجی‌های Markdown (قابل استفاده در Obsidian) و نسخه‌بندی (Git history) استفاده می‌شود.

## ساختار پیشنهادی
- `vault/` : فایل‌های Markdown که قرار است در Obsidian باز شوند
- `vault/_meta/` : فایل‌های متادیتا و نگاشت‌ها

## قواعد کلی
- بار اول: خروجی کامل
- دفعات بعد: فقط تفاوت‌ها
- قبل از تغییر هر فایل: تأیید دستی
- در تعارض: از شما سؤال می‌شود
